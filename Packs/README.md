# 📦 DubMate Scene Packs Directory

Place your scene packs into this folder.

## How to Get Scene Packs

1. **Download or Create Scene Packs**:
   - Create your own scene packs in seconds using the built-in **DubMate Pack Builder Studio** (`/builder.html`).
   - Or browse and download community packs on [GameBanana Choicer Voicer Mods](https://gamebanana.com/mods/cats/44064).

2. **Install Pack**:
   - Extract/place the pack folder directly into this `Packs/` folder (or drag and drop `.zip` files directly into DubMate).
   - Click **Rescan** in the DubMate web interface (or restart the server). DubMate natively supports both DubMate and Choicer Voicer pack structures.

## Pack Folder Structure
Each pack folder inside `Packs/` should contain:
```
Packs/
└── Your_Scene_Name/
    ├── dub_video.mp4 (or dub_video.ogv)
    ├── _backing_track.wav
    ├── _captions.json
    ├── 01_Character_0-120.wav
    └── ...
```
