DubMate needs your microphone

Every dub take is recorded locally from your mic and mixed against the scene's backing track. Without microphone access the recording booth cannot capture anything.

  • 🎙️ Your browser will now ask for permission. Choose Allow.
  • 💾 Takes stay on this machine and are only shared with your room when you save them.
  • 🎚️ Afterwards you can pick the exact input and output device and check your levels.
🚫 Microphone access was blocked

The browser refused the request, so recording is disabled until access is restored.

In the DubMate window
  1. Click the padlock / sliders icon in the address bar.
  2. Set Microphone to Allow.
  3. Reload the page, then press Try Again below.
Windows privacy settings
  1. Open Settings → Privacy & security → Microphone.
  2. Turn on Microphone access and Let desktop apps access your microphone.
  3. Restart DubMate Studio so the desktop window re-asks.

The DubMate desktop build runs inside a system webview, so Windows can block the mic even when the browser permission looks fine. On macOS the equivalent is System Settings → Privacy & Security → Microphone.
