    🚫 Microphone access was blocked

    Recording is off until you allow microphone access.

    In the DubMate window
    1. Click the padlock / sliders icon in the address bar.
    2. Set Microphone to Allow.
    3. Reload the page, then press Try again.
    Windows privacy settings
    1. Open Settings → Privacy & security → Microphone.
    2. Turn on Microphone access and Let desktop apps access your microphone.
    3. Restart DubMate.

    On a Mac: System Settings → Privacy & Security → Microphone.
